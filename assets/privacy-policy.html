yt-dlp Web UI — Privacy Policy

本文档为双语隐私政策。英文版在前，中文版在后。（This document is bilingual: English first, Chinese below.）

1. Overview

yt-dlp Web UI is a self-hosted web interface for the yt-dlp downloader. It runs entirely on your own NAS device (TerraMaster TOS 7). The application itself does not collect, transmit or share any personal data with the publisher or any third party: there is no analytics, no telemetry, no tracking and no advertising.

2. Data stored on your device

DataLocationPurpose
Downloaded media files/var/lib/ytdlpwebui/downloads (or the directory you configure)The content you asked to download
Download queue / history database/var/lib/ytdlpwebui/bolt.dbLocal queue persistence so downloads survive restarts
Application log/var/lib/ytdlpwebui/yt-dlp-webui.logLocal troubleshooting
App configuration/usr/local/ytdlpwebui/config.yml, /usr/local/ytdlpwebui/ytdlpwebui.envListen address, port, paths, queue size
Browser settings (theme, language, templates)Your browser's local storageUI preferences only; not sent to the server

All of this data stays on your device. It is never uploaded to the publisher or to any intermediary.

3. Your rights: access, correction, deletion

  • Access: the built-in file browser lists every downloaded file; the queue and history are shown in the web UI.
  • Correction: change settings in the web UI or edit the configuration files listed above, then restart the service.
  • Deletion: delete files in the web UI; apt remove (or App Center uninstall) keeps data, apt purge deletes /var/lib/ytdlpwebui entirely. No remote copy exists because nothing was ever uploaded.

4. Third-party network access (user-initiated only)

The application contacts external services only for the operations you explicitly perform:

  • Download sources: when you submit a video/playlist URL, yt-dlp on your NAS connects directly to that site to retrieve the media. The destination is the site you chose.
  • yt-dlp update check: only when you press the update button in the web UI, yt-dlp contacts its own release channel.
  • YouTube JavaScript challenge data: yt-dlp may fetch an auxiliary solver component from GitHub while processing a YouTube URL. This carries no personal data.
  • Nothing else: no data is sent to the publisher, no usage statistics phone home, no crash reporting exists.

5. Accounts and children

The application has no account system of its own: access is protected by your TerraMaster TOS login through the TOS web server. It serves your LAN and does not knowingly process children's data.

6. Changes and contact

This policy ships inside the application package (/usr/local/ytdlpwebui/privacy-policy.html, also served at /ytdlpwebui/privacy-policy.html). Questions or reports: https://github.com/Moechz/yt-dlp-web-ui/issues. Upstream project: https://github.com/marcopiovanello/yt-dlp-web-ui (GPL-3.0).

yt-dlp Web UI — 隐私政策（中文）

1. 概述

yt-dlp Web UI 是 yt-dlp 下载器的自托管网页界面，完全运行在您自己的 NAS 设备（TerraMaster TOS 7）上。应用本身不向发布者或任何第三方收集、传输、共享任何个人数据：无统计、无遥测、无跟踪、无广告。

2. 存储在您设备上的数据

数据位置用途
已下载的媒体文件/var/lib/ytdlpwebui/downloads（或您配置的目录）您请求下载的内容
下载队列 / 历史数据库/var/lib/ytdlpwebui/bolt.db本地队列持久化，重启后任务不丢失
应用日志/var/lib/ytdlpwebui/yt-dlp-webui.log本地排障
应用配置/usr/local/ytdlpwebui/config.yml、/usr/local/ytdlpwebui/ytdlpwebui.env监听地址、端口、路径、队列长度
浏览器设置（主题、语言、模板）您浏览器的本地存储仅界面偏好，不会发送到服务器

以上数据全部留在您的设备上，应用不会将其上传给发布者或任何中间方。

3. 您的权利：访问、更正、删除

  • 访问：内置文件浏览器可列出全部已下载文件；队列与历史记录在网页界面中展示。
  • 更正：在网页界面修改设置，或编辑上述配置文件后重启服务。
  • 删除：在网页界面删除文件；apt remove（或应用中心卸载）保留数据，apt purge 彻底删除 /var/lib/ytdlpwebui。因从未上传，任何远端都不存在副本。

4. 第三方网络访问（仅由您主动发起）

应用仅在您明确执行操作时访问外部服务：

  • 下载源：当您提交视频/播放列表 URL 时，NAS 上的 yt-dlp 直接连接该站点获取媒体，目的地为您选择的站点。
  • yt-dlp 更新检查：仅当您在网页界面点击更新按钮时，yt-dlp 才会访问其官方发布渠道。
  • YouTube JavaScript 挑战数据：处理 YouTube 链接时，yt-dlp 可能从 GitHub 获取辅助求解组件，不含任何个人数据。
  • 除此之外没有其他外联：不向发布者发送任何数据、无使用统计回连、无崩溃上报。

5. 账户与儿童

应用自身没有账号体系：访问由 TerraMaster TOS 登录经 TOS 网页服务统一鉴权。应用服务您的局域网，不涉及儿童数据的处理。

6. 变更与联系

本政策随应用包分发（/usr/local/ytdlpwebui/privacy-policy.html，亦经 /ytdlpwebui/privacy-policy.html 提供）。问题或报告请至 https://github.com/Moechz/yt-dlp-web-ui/issues。上游项目：https://github.com/marcopiovanello/yt-dlp-web-ui（GPL-3.0）。
